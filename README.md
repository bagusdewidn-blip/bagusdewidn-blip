### 🚀 Proyek Utama

* **[Konter Digital](https://konter-digital.com)** *(Web & Flutter App)*  
  Platform transaksi PPOB, pulsa, paket data, dan *top-up* e-wallet berbasis Host-to-Host (H2H). Dilengkapi manajemen agen berjenjang, *routing* pemasok otomatis, kunci idempotensi transaksi, serta aplikasi klien berbasis Flutter.
* **PRABA (Portal Pemerintahan Kecamatan)** *(Laravel & MySQL)*  
  Sistem informasi e-government dan pelaporan administrasi desa-ke-kecamatan untuk Kecamatan Tungkal Ilir, memisahkan alur kerja administratif (PPD) dan pemberdayaan masyarakat/fisik (PMD) secara terstruktur.
* **[Nimmy Stream App](https://github.com/bagusdewidn-blip/nimmy-app)** *(Android)*  
  Rilis resmi aplikasi *streaming* berbasis Android dengan antarmuka ringan.
* **BASING (Banyuasin Sigap)** *(Local AI Assistant)*  
  Eksperimen model bahasa lokal berbasis Ollama yang dikustomisasi menggunakan dataset kosakata dan dialek lokal Banyuasin.
